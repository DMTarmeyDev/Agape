# Agape Roadmap

This roadmap communicates direction rather than guaranteed delivery dates.

## 1. Stabilise the alpha

- strengthen installer reliability;
- expand functional and end-to-end testing;
- improve recovery, checkpoints, and rollback;
- make failures visible and actionable;
- keep completed workflow sections compact and reopenable.

## 2. Human-first product experience

- simplify common workflows;
- hide technical internals by default;
- improve document creation and download flows;
- improve progress, status, and recovery information;
- make advanced controls available through progressive disclosure.

## 3. Model and provider flexibility

- preserve routing across available AI models/providers;
- support local and online models;
- improve connector validation and fallback behaviour;
- keep credentials out of source control.

## 4. Cross-platform delivery

- mature Windows packaging;
- expand macOS and Linux support;
- keep a shared core codebase where practical;
- add platform-specific validation.

## 5. Extensibility and automation

- improve optional tool/plugin installation;
- strengthen safe terminal/automation loops;
- expand integration tests;
- document extension points for contributors.

## 6. Mobile companion

- explore a lightweight mobile client backed by the main Agape service;
- keep heavy compute and automation off-device where appropriate.

Progress should be tracked in GitHub Issues and Discussions so contributors can see what is active, blocked, or ready for help.
