# Agape V5.6.1 R2.6.0 - Project-first workflow

- Create begins by deciding what the project entails before exposing specialist controls.
- Supports automatic classification or Document, Software/Coding, Research, Business/Planning, Automation/Workflow and Communications.
- Agape produces a small capability/tool plan for that project.
- Coding options are hidden unless development/automation is selected.
- Project type is carried into execution planning so routing follows the chosen job.
- The existing Source -> Review -> Result workflow remains underneath the project-specific front door.
