# Code of Conduct

Agape aims to maintain a constructive, useful, and welcoming project community.

## Expected behaviour

Participants should:

- discuss ideas and code rather than attacking people;
- give clear, actionable technical feedback;
- respect different levels of experience;
- avoid harassment, discrimination, threats, or deliberate disruption;
- avoid posting private information, credentials, or confidential material;
- help keep Issues and Discussions on topic.

## Maintainer actions

Maintainers may edit, hide, lock, or remove content that is abusive, unsafe, spammy, off-topic, or exposes private/security-sensitive information. Repeated or serious misconduct may result in participation restrictions.

## Reporting conduct problems

For ordinary moderation concerns, contact the repository maintainer through an appropriate private channel. Security vulnerabilities should follow `SECURITY.md`.
