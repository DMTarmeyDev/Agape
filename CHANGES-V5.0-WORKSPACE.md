# Agape V5.0 - Workspace

V5.0 adds a human-first Workspace reachable from the main navigation.

- VS Code-style project/results filing tree on the left.
- Selected project or result details in the centre.
- Persistent local to-do checklist on the right.
- Recent Agape jobs on the right with status.
- Projects can be sent directly back to Create.
- Jobs can be checked/resumed from Workspace.
- Real-click browser QA now includes Workspace navigation and an add/check/delete to-do cycle.
- No AI work, external installation or recovery action is triggered by the safe click gate.
