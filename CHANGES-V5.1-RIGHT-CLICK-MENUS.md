# Agape V5.1 - Right-click menus

Workspace now provides context-sensitive right-click menus for projects, results/jobs and to-do items.

- Projects: Open, Use as source, Add to to-do, Copy name/ID.
- Jobs/results: Open details, Check/resume when supported, Add to to-do, Copy name/ID.
- To-do: Complete/reopen, Edit, Copy text, Delete.
- Blank file-tree area: Refresh, Add to-do, Collapse folders.
- Menus close on outside click, Escape, or window blur.
