# Agape V4.8 - Coding Tools

- Separates coding model, coding agent, and code manager.
- Coding agents: Auto, Agape Native, Aider, OpenHands, Open Interpreter, Compare engines.
- Code managers: Agape workspace, Theia Lite, Theia Full, VS Code.
- Default coding model policy is Auto - coding specialist.
- Settings can install VS Code through the existing allow-listed winget path.
- Settings can open the official Eclipse Theia Windows download and then detect/open Theia once installed.
- OpenHands setup points to its official Windows/WSL instructions.
- Open Interpreter remains experimental until its exact local binary/install contract is verified.
- Selected coding choices are persisted and attached to development run payloads.
