AGAPE GITHUB-READY RECOVERY

Recommended first push: PRIVATE.
The recovered tree was scanned for obvious private-key files and hard-coded credential assignments. No private-key file was found, but recovered authentication/connectors code exists, so review before changing the repository to public.

To publish:
1. Extract this ZIP.
2. Open PowerShell in the extracted folder.
3. Run:
   Set-ExecutionPolicy -Scope Process Bypass -Force
   .\PUBLISH-TO-GITHUB.ps1

Default repo name: agape-recovered
Default visibility: private

For a different name:
   .\PUBLISH-TO-GITHUB.ps1 -RepoName "Agape" -Visibility private

For public publishing only after review:
   .\PUBLISH-TO-GITHUB.ps1 -RepoName "Agape" -Visibility public
