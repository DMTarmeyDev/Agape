# Support

## Questions and usage help

Use **GitHub Discussions** for:

- setup and installation questions;
- how-to questions;
- workflow ideas;
- model/provider integration questions;
- general feedback.

Discussions: https://github.com/DMTarmeyDev/Agape/discussions

## Bugs

Use **GitHub Issues** for reproducible bugs.

Issues: https://github.com/DMTarmeyDev/Agape/issues

Please include:

- operating system and version;
- Agape version/commit;
- exact steps to reproduce;
- expected result;
- actual result;
- relevant logs with secrets removed.

## Feature requests

Feature requests are welcome through the feature request Issue form. Explain the user problem first, then the proposed solution.

## Security reports

Do not report vulnerabilities publicly. Follow `SECURITY.md` and use GitHub's private security reporting/advisory flow when available.

## Secrets and private data

Never post API keys, access tokens, passwords, personal information, private documents, or production credentials in Issues, Discussions, logs, or screenshots.
